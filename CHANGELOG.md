# Mobile app changelog

Changes are grouped by the app version users receive. See [the versioning policy](docs/versioning.md) for build numbers and release steps.

## Unreleased — 1.0.0 development baseline

### Added

- WakaTime sign-in and API key connection.
- Coding dashboard, daily goals, insights, leaderboards, and local activity cache.
- Appearance and sync preferences in Settings.
- Open source credits and license links in Settings.
- App updates page with the installed OTA ID, update status, a manual check, and a mobile data preference.

### Changed

- Emphasized key values in the analytics activity summary.
- Added selection haptics to bottom tabs and switches.

Before a first distribution, review this list against the tested binary, record both platform build numbers and the source commit, then date this section.
