# Android native tab icons

These are the `regular` and `fill` weights of Phosphor's House, ChartDonut, Ranking, and GearSix icons. The SVG paths came from the installed `phosphor-react-native` definitions; the matching PNGs are used by Expo Router's Android native tabs.

Android displays custom image tab icons in their original colors, so each weight has a light and dark asset. Default icons use the theme's `muted` color and selected icons use `primary` from `src/global.css`. Update both asset sets when those palette colors change.
